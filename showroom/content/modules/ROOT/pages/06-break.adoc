= 6. Break it safely

Repeat the same request through the declared unavailable condition. Keep the VM,
Service, schemas, correlation rules, and human authority unchanged.

[source,bash]
----
oc -n "$LAB_NAMESPACE" port-forward service/virtualization-ai-201-adapter 8080:8080
curl --fail-with-body -sS \
  -H 'Content-Type: application/json' \
  -H 'X-Qualification-Condition: unavailable' \
  --data @contracts/examples/qualified-request.json \
  http://127.0.0.1:8080/api/v1/qualify | python3 -m json.tool
----

The response must say `MODEL_UNAVAILABLE`, set `ai_participated` to `false`,
and omit `advisory` and `model`. A fallback explanation is not a live AI result.

Checkpoint: the failure names the boundary and preserves evidence without
inventing a category, summary, rationale, model identity, or action.
