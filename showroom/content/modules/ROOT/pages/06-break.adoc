= 6. Break it safely

== Do

Repeat the same request through the declared unavailable condition. Keep the
VM, Service, schemas, correlation rules, and human authority unchanged.

[source,bash,role="execute"]
----
curl -fsS -X POST "$ADAPTER_URL/api/v1/qualify?condition=unavailable" \
  -H 'Content-Type: application/json' \
  --data-binary @"$LAB_DIR/request.json" \
  | tee "$LAB_DIR/unavailable-response.json" | jq .
----

== Learn

An unavailable model must fail closed. A fallback explanation is not a live AI
result and must not be presented as one.

== Prove

[source,bash,role="execute"]
----
jq -e '
  .outcome == "MODEL_UNAVAILABLE" and
  .ai_participated == false and
  .validation == "FAIL_CLOSED" and
  .authority == "HUMAN_REVIEW_REQUIRED" and
  (has("advisory") | not) and (has("model") | not)
' "$LAB_DIR/unavailable-response.json"
----

The result names the failed boundary and preserves evidence without inventing
a category, summary, rationale, model identity, or action.
